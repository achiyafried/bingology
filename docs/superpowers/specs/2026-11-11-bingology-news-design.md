# Bingology — "מה חדש"

**תאריך:** 2026-11-11
**סטטוס:** אושר בשיחה (מוקאפ), טיוטה לבדיקה

## מטרה

עמוד "מה חדש" כללי על כל 1001 הסדרות באתר, לכל מבקר, בלי חשבון: עונות חדשות שהוכרזו, עונות שהתחילו, סדרות שהסתיימו או בוטלו, וסדרות שעלו לשירות סטרימינג או ירדו ממנו בישראל, ארה״ב ובריטניה.

**הצלחה נראית כך:** נכנסים לאתר, רואים נקודה על הפעמון ושלוש ידיעות במסך הפתיחה ("Severance · עונה 3 ב-14 במרץ"), לוחצים "כל החדשות" ורואים את השבועיים האחרונים לפי ימים — וכל זה נוצר לבד מהעדכון הלילי, בלי עריכה ידנית.

## מחוץ לתחום (כרגע)

- כתבות, ביקורות, פרסים וטריילרים ממקורות חיצוניים.
- ידיעה על כל פרק חדש (מציף).
- סינון "רק שלי" לפי האזור האישי (אפשר להוסיף אחרי שהאזור האישי יעלה).
- התראות push או מייל.
- מדינות מעבר ל-IL / US / UK.

## מקור הנתונים

אין מקור חדש. הסקריפט הלילי כבר מושך לכל סדרה את `/tv/{id}` עם `watch/providers`. החדשות נוצרות מ**השוואה בין הנתונים של הלילה לנתונים של הלילה הקודם** (`site/data.json` הקודם, שכבר נקרא היום לצורך fallback).

שדות חדשים ב-`site/data.json` (ב-`transformTv`, בלי בקשות נוספות):

| שדה | מקור ב-TMDB | דוגמה |
|---|---|---|
| `next` | `next_episode_to_air` → `{ season, episode, date }` או `null` | `{ "season": 3, "episode": 1, "date": "2027-03-14" }` |
| `streams` | `watch/providers.results.{IL,US,GB}.flatrate[].provider_name` | `{ "IL": ["Apple TV+"], "US": ["Apple TV+"], "UK": ["Apple TV+"] }` |

ב-`streams` הקוד `GB` של TMDB נשמר כ-`UK`. השמות נשמרים כמו שהם ב-TMDB, כדי שהידיעה תגיד בדיוק איפה ("Sky Go", "Hulu").

## סוגי ידיעות

| `kind` | מתי נוצרת (השוואה בין אתמול להיום) | תגית במסך |
|---|---|---|
| `announced` | היום יש `next` עם `episode = 1` ו-`season` גדולה ממספר העונות של אתמול, ואתמול לא היה `next` לאותה עונה עם אותו תאריך (תאריך שהשתנה = ידיעה חדשה) | עונה חדשה הוכרזה |
| `premiere` | פרק 1 של עונה ≥ 2 שודר מאז הריצה הקודמת: `seasons` עלה, או `next` של אתמול (`episode = 1`) הוא עם תאריך ≤ היום | התחילה היום |
| `ended` | `status` עבר ל-`ended` | הסתיימה |
| `canceled` | `status` עבר ל-`canceled` | בוטלה |
| `stream_added` | שם שירות הופיע ב-`streams[region]` ולא היה אתמול | עלתה לסטרימינג |
| `stream_removed` | שם שירות היה אתמול ב-`streams[region]` ואיננו היום | ירדה מסטרימינג |

**לא נוצרות ידיעות:**
- בריצה הראשונה (אין `data.json` קודם, או שדות `next`/`streams` חסרים אתמול).
- לסדרה שנכנסה היום למאגר הרחב או יצאה ממנו — רק לסדרות שקיימות בשני הימים.
- לסדרה שהבקשה שלה נכשלה הלילה (הנתונים שלה הם עותק מאתמול).

**מניעת רעש בסטרימינג:** הנתונים של JustWatch "מהבהבים". ידיעת `stream_added` / `stream_removed` שמתבטלת בתוך 7 ימים (ירד וחזר, או עלה וירד) — שתי הידיעות נמחקות.

**מבנה ידיעה:**
```json
{ "id": "95396-announced-3-2027-03-14", "date": "2026-11-11", "tmdbId": 95396,
  "kind": "announced", "season": 3, "airDate": "2027-03-14" }
{ "id": "136315-stream_added-IL-Disney Plus", "date": "2026-11-10", "tmdbId": 136315,
  "kind": "stream_added", "region": "IL", "provider": "Disney Plus" }
```
`id` יציב, כך שאותה ידיעה לא נכנסת פעמיים.

## אחסון

`site/news.json` — נוצר ונשמר על ידי העדכון הלילי, כמו `data.json`:
```json
{ "updatedAt": "2026-11-11T03:12:00Z", "items": [ ...מהחדש לישן ] }
```
נשמרות ידיעות של **60 הימים האחרונים**, עד **400** ידיעות. ידיעות חדשות מתווספות בראש, כפילויות לפי `id` נזרקות.

אם העדכון הלילי נכשל (כמו היום) — `news.json` לא משתנה.

## יחידות

| קובץ | תפקיד |
|---|---|
| `scripts/lib/tmdb.mjs` | `transformTv` מחזיר גם `next` ו-`streams` |
| `scripts/lib/merge.mjs` | `next` ו-`streams` עוברים ל-`data.json` (live בלבד; בלי fallback מאתמול, כדי לא לייצר ידיעות מנתונים ישנים) |
| `scripts/lib/news.mjs` | **טהור:** `diffNews(prevSeries, currSeries, today) -> item[]`, `mergeNews(prevNews, newItems, today) -> news` (60 יום / 400, כפילויות, ביטול הבהובים) |
| `scripts/fetch-data.mjs` | אחרי ה-merge ולפני הכתיבה: קורא `site/news.json` הקודם, מחשב ושומר. כישלון בחדשות לא מכשיל את העדכון — נרשמת אזהרה ו-`news.json` נשאר |
| `.github/workflows/update-data.yml` | ה-commit כולל גם `site/news.json` |
| `site/lib/news.js` | **טהור:** `newsText(item, s) -> {tag, title, sub}` בעברית, `groupByDay(items, today)` (היום / אתמול / השבוע / קודם), `unseenCount(items, lastSeen)` |
| `site/views/news.js` | רצועה במסך הפתיחה + עמוד מלא. נטען בדינמיות |
| `site/app.js` | פעמון ליד הלוגו, הרצועה במסך הפתיחה, ניתוב `#news` |

## מסכים

כפי שאושר במוקאפ:

1. **פעמון** משמאל ללוגו (בכיוון RTL: בצד השני של הלוגו). נקודה אדומה כשיש ידיעות חדשות מאז הביקור האחרון בעמוד החדשות (`localStorage` `bingology:newsSeen` = ה-`date` של הידיעה החדשה ביותר שנראתה). לחיצה פותחת את העמוד.
2. **רצועת "מה חדש"** במסך הפתיחה, מתחת ל"או פשוט תפתיעו אותי": 3 הידיעות האחרונות + "כל החדשות ←". אין ידיעות → הרצועה לא מוצגת.
3. **עמוד "מה חדש"** (`#news`): כותרת, "חזרה", צ׳יפים לסינון — הכל / עונות חדשות (`announced`, `premiere`) / סטרימינג (`stream_*`) / הסתיימו (`ended`, `canceled`) — וידיעות מקובצות לפי היום / אתמול / השבוע / קודם. לכל ידיעה: פוסטר, תגית בצבע לפי סוג, כותרת, שורת משנה. בידיעות סטרימינג — תגית מדינה (IL / US / UK). לחיצה על ידיעה פותחת את כרטיס הסדרה הקיים.

**נוסחים (דוגמאות מחייבות):**
- `announced`: תגית "עונה חדשה הוכרזה", כותרת "Severance · עונה 3 ב-14 במרץ 2027", שורת משנה: השירותים ב-IL (או US אם אין ב-IL).
- `premiere`: "התחילה היום" (או "התחילה" אם לא היום), "Slow Horses · עונה 5".
- `stream_added`: "עלתה לסטרימינג", "The Bear · Disney Plus" + תגית IL.
- `stream_removed`: "ירדה מסטרימינג", "Succession · ירדה מ-Sky Go" + תגית UK; שורת משנה "עדיין ב-…" אם יש שירות אחר באותה מדינה או בישראל.
- `ended`: "הסתיימה", שורת משנה "כל הפרקים זמינים לבינג׳".
- `canceled`: "בוטלה", שורת משנה "אחרי N עונות".

סדרה שכבר לא במאגר (`tmdbId` לא ב-`data.json`) — הידיעה עליה לא מוצגת.

## טיפול בשגיאות

- `news.json` חסר או פגום באתר → הרצועה והפעמון לא מוצגים; עמוד `#news` מציג "אין חדשות כרגע". שאר האתר לא מושפע.
- `news.json` הקודם פגום בזמן העדכון → מתחילים רשימה ריקה ונרשמת אזהרה.
- `next.date` חסר → אין ידיעת `announced` (רק כשיש תאריך).

## בדיקות

- **יחידה (`node --test`):**
  - `transformTv`: `next` ו-`streams` (כולל `GB`→`UK`, אזור חסר → `[]`, אין `next` → `null`).
  - `diffNews`: כל אחד מששת הסוגים; ריצה ראשונה → `[]`; סדרה חדשה במאגר → כלום; תאריך עונה שהשתנה → ידיעה חדשה; אותו תאריך → כלום.
  - `mergeNews`: כפילויות, חיתוך 60 יום ו-400, הבהוב בתוך 7 ימים נמחק, הבהוב אחרי 8 ימים נשאר.
  - `newsText` לכל סוג, `groupByDay` בגבולות חצות, `unseenCount`.
- **ידנית בדפדפן:** `news.json` לדוגמה (fixture), מובייל, בהיר וכהה: פעמון עם נקודה ובלי, רצועה, עמוד, סינון, לחיצה פותחת כרטיס.
